## Content Duplication Architecture

- English TS (`data/content/`) is source of truth; locale JSON overlays deep-merge required fields
- Market JSON overlays regional English on same TS base
- UI chrome (`ui.json`) shared structure, translated strings
- Review testimonial bodies remain English on localized Reviews pages
- Learn articles: no locale overlays
